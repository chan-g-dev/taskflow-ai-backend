# 🚀 TaskFlow AI Backend

An AI-Powered Personal Productivity Platform built with FastAPI.

## 📖 Overview

TaskFlow AI is a production-style backend project designed to help users manage projects, tasks, and daily productivity with AI-assisted planning.

This project is being built to demonstrate modern backend engineering practices using Python and FastAPI.

## 🎯 Goals

- Build production-ready REST APIs
- Secure authentication using JWT
- AI-powered task prioritization
- Dockerized development
- AWS deployment
- Automated testing
- Professional software architecture

## 🛠️ Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Redis
- Docker
- AWS
- GitHub Actions
